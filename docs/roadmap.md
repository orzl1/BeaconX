# 路线图

每个里程碑都以「可验收」为准，不以「代码写完」为准。当前处于 **M0**。

| 阶段 | 目标 | 验收标准 |
| --- | --- | --- |
| **M0 骨架**（当前） | 可运行进程、声明式 HTTP + 中间件、版本化迁移、租户预留、健康检查、CI（含 Windows 交叉编译）、品牌门禁 | `docker compose up` 后 5 分钟内 `/readyz` 返回 200；CI 全绿；三平台可编译 |
| **M1 数据与图** | 租户、资产与身份、任务范围、资产图 + 作战图、锚点与覆盖度、迁移 v1 | 双租户夹具不串数据；覆盖度语义有单测；10 万资产查询 P95 < 200ms |
| **M2 运行时与引擎** | 任务状态 reducer + 事件、准入调度、规划/执行循环、动作租约、SSE 回放 | kill -9 后无永久 running；暂停/恢复/删除可用；断线补洞无丢失 |
| **M3 规划与执行** | 目标分解、态势快照、结构化规划决策、计划依赖图、过程检索、上下文压缩、预算与收尾 | 同一组靶场任务的完成率达标；规划输出 100% 通过 schema 校验；依赖派发用例通过 |
| **M4 工具与策略** | 工具注册表（schema 生成）、MCP 连接池、技能版本化；策略规则 + 审批 + 模型兜底 + 审计；统一拦截入口与启动自检 | 工具面按角色收敛；审批/超时/审计用例通过；所有执行型 Agent 均受策略检查 |
| **M5 证据与模型路由** | 采集两阶段、脱敏与加密、证据版本令牌、复测；单层模型路由 + 结构化错误 + 预算 | 篡改证据必失败；预算超限可暂停；模型故障切换有单一来源日志 |
| **M6 前端与交付** | 由 OpenAPI 生成客户端、页面按功能域拆分、SSE/查询 hooks、图可视化、e2e；自更新与发布链（macOS/Linux） | 5 条 e2e 全绿；发布包带校验和；升级回滚演练通过 |

## 后续方向

- **v1.1**：审批推送（IM/Webhook）、审计导出、审批工作台增强。
- **v2**：执行期授权策略（动作 × 目标编译）、fail-closed 默认、不可删除的安全底线、策略快照 API。
- **多租户**：从字段预留升级为行级隔离（RLS + 租户级认证），不需要数据搬迁。
- **Windows 正式支持**：服务化、安装器、证书存储集成；v1 仅保证可编译。

## 非目标（v1）

- 多租户隔离、多用户角色体系
- Windows 官方发布包
- 执行期授权策略引擎
- 扫描器编排（能力仍由 Agent 通过工具完成）
